# SCRIPT THE PYTHON PARA MODIFICAR CALIDAD DE IMAGENES



## NECESIDAD

Este Script de python surge de la necesidad de bajar la calidad de imagenes JPG para poder subirlas a una pagina web, ya que muchas veces las imagenes tienen un peso muy grande y no se pueden subir a la web.
ya que muchas plataformas solo te permiten subir hasta 1MB de peso, y muchas veces las imagenes que se sacan con la camara del celular o con la camara de una computadora tienen un peso muy grande, por lo que es necesario bajar la calidad de la imagen para poder subirla a la web.


## DESCRIPCION
La aplicacion es sencilla, el usuario solo necesita seleccionar una imagen de su computadora, y la 
arrastra a la ventana de la aplicacion, luego el usuario puede seleccionar la calidad de la imagen que desea, y finalmente puede guardar la imagen con la calidad seleccionada.
La aplicacion solo acepta imagenes en formato JPG, y no acepta imagenes en otros formatos"""

-Python 3.0 o superior


## INSTALACION

Se necesitan bajar las librearias necesarias para que la aplicacion funcione, para eso se necesita ejecutar el siguiente comando en la terminal:
```
pip install PySide6 Pillow
```
Aunque las librerias necesarias y sus versiones ya vienen especificadas en el archivo requirements.txt, por lo que se puede ejecutar el siguiente comando en la terminal:
```
pip install -r requirements.txt
```


## USO

1. Ejecuta el script.
2. Arrastra una imagen JPG a la ventana de la aplicacion.
3. Selecciona la calidad de la imagen que deseas.
4. Haz click en el boton "Aceptar" para guardar la imagen con la calidad seleccionada.
